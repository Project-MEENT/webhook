/errors/

#api-key-missing

Returned when a request to a protected resource does not include an Authorization: Bearer {api-key} header.

Request: POST /api/data and GET /api/data

Response: 401 Unauthorized

#data-conversion-error

Returned when the webhook cannot convert received data to Turtle format for storage in the Solid Pod.

Request: POST /api/v0.4/data

Response: 500 Internal Server Error

#invalid-api-key

Returned when a Bearer token is provided with a request , but there is no matching API key registration for that token.

Request: POST /api/data

Response: 401 Unauthorized

#invalid-api-version

Returned when the requested API version is not available or cannot be parsed.

Request: Any /api/ request with invalid version

Response: 404 Not Found

#invalid-auth-header

Returned when the Authorization header exists but does not start with the required Bearer scheme.

Request: POST /api/data

Response: 400 Bad Request

#invalid-json

Returned when the provided request body is not valid JSON.

Request: POST /api/v0.4/data with malformed JSON

Response: 422 Unprocessable Entity

#invalid-path

Returned when the requested data path does not resolve to a stored .data object below the expected directory structure.

Request: GET /api/data/{object}

Response: 400 Bad Request

#invalid-timestamp

Returned when the timestamp value in the provided JSON data cannot be parsed as a valid timestamp.

Request: POST /api/v0.4/data with invalid timestamp

Response: 422 Unprocessable Entity

#invalid-url

Returned when a submitted WebID is present, but is not a valid URL.

Request: POST /api/register, POST /api/v0.4/consent, and GET /api/v0.4/data

Response: 422 Unprocessable Entity

#method-not-allowed

Returned when a route is valid but the HTTP method is not, for instance when a GET request is made to a POST endpoint.

Request: /api/data and /api/register

Response: 405 Method Not Allowed

#method-not-implemented

Returned when a method is recognized but has not yet been implemented for the requested endpoint.

Request: PUT /api/register or other unimplemented methods

Response: 501 Not Implemented

#missing-timestamp

Returned when the required timestamp field is missing from the JSON data being posted to the webhook.

Request: POST /api/v0.4/data without timestamp field

Response: 422 Unprocessable Entity

#no-data-received

Returned when the request body is empty. On the data endpoint this means no meter payload was supplied; on the register endpoint it means no WebID was submitted.

Request: POST /api/data and POST /api/register

Response: 422 Unprocessable Entity

#no-storage-url

Returned when the webhook cannot resolve a storage URL for the provided WebID. This occurs when fetching or storing data in a Solid Pod.

Request: GET /api/v0.4/data or POST /api/v0.4/data

Response: 422 Unprocessable Entity

#not-found

Returned when a requested resource does not exist

Request: Any unknown or unsupported API route, or non-existing file in /data/

Response: 404 Not Found

#provider-error

Returned when the OIDC provider (authorization server) returns an error during the authentication flow.

Request: GET /api/v0.4/consent?error=...

Response: 502 Bad Gateway

#response-encoding-failed

Returned when the final problem or data response cannot be converted to JSON, for example because the response payload contains an unsupported value.

Request: Any endpoint returning JSON, such as /api/

Response: 500 Internal Server Error

#solid-error

Returned when an error occurs during Solid Pod authentication or authorization. See specific error types (#provider-error, #solid-fetch-error, #solid-write-error) for details on particular failure modes.

Examples include:

  • Provider returned an error in the authorization response
  • Provider did not return an authorization code
  • Provider did not return a state parameter
  • CSRF check failed (state mismatch)
  • Provider did not return a valid WebID in the id_token
  • Provider did not return a refresh_token when offline access was required
  • Failed to discover OIDC issuer metadata
  • Could not resolve an OIDC issuer from the provided WebID
  • Upstream token/resource endpoints rejecting or timing out requests

Request: GET /api/v0.4/consent?code=...&state=... or POST /api/v0.4/consent

Response: 502 Bad Gateway for upstream failures, 504 Gateway Timeout for upstream timeouts, 500 Internal Server Error for webhook session/state errors, and propagated upstream 4xx (including 511 for upstream auth failures)

#solid-fetch-error

Returned when an error occurs while fetching a resource from a Solid Pod.

Examples include:

  • Network error or timeout reaching the Solid Pod
  • Authentication/authorization failure from the Solid Pod
  • Resource not found on the Solid Pod

Request: GET /api/v0.4/data/{path}

Response: 502 Bad Gateway

#solid-write-error

Returned when an error occurs while writing a resource to a Solid Pod.

Examples include:

  • Network error or timeout reaching the Solid Pod
  • Authentication/authorization failure from the Solid Pod
  • Storage quota exceeded on the Solid Pod
  • Permission denied to write to the requested location

Request: POST /api/v0.4/data

Response: 502 Bad Gateway

#unexpected-error

Catch-all problem for unhandled server errors, including unexpected logic or routing failures.

Request: Any /api/ request

Response: 500 Internal Server Error

#unexpected-output

Returned when unexpected server output appears before the response is complete. The captured output is included in the error detail for debugging.

Request: Any endpoint, including /api/, /docs/, or /errors/

Response: 500 Internal Server Error

#webid-already-registered

Returned when a submitted WebID has already been registered. Use PUT to update an existing registration (requires Authorization header).

Request: POST /api/register

Response: 409 Conflict

#webid-not-connected

Returned when attempting to register a WebID that has not yet been authenticated with the webhook. The user must first complete the authentication flow at the provided consent URL.

Request: POST /api/v0.4/register with unconnected WebID

Response: 407 Proxy Authentication Required

#write-failed

Returned when the storage layer fails while checking, reading, writing, or creating stored API resources.

Request: Any /api/ request that triggers a storage failure

Response: 502 Bad Gateway
