/errors/

#api-key-missing

Returned when a request to a protected resource does not include an Authorization: Bearer {api-key} header.

Request: POST /api/data and GET /api/data

Response: 401 Unauthorized

#invalid-api-key

Returned when a Bearer token is provided with a request , but there is no matching build/data/keys/{api-key}.key registration.

Request: POST /api/data

Response: 401 Unauthorized

#invalid-auth-header

Returned when the Authorization header exists but does not start with the required Bearer scheme.

Request: POST /api/data

Response: 400 Bad Request

#invalid-path

Returned when the requested data path does not resolve to a stored .data object below the expected directory structure.

Request: GET /api/data/{object}

Response: 400 Bad Request

#invalid-url

Returned when the registration body is present, but the submitted WebID is not a valid URL.

Request: POST /api/register

Response: 422 Unprocessable Entity

#method-not-allowed

Returned when a route is valid but the HTTP method is not, for instance when a GET request is made to a POST endpoint.

Request: /api/data and /api/register

Response: 405 Method Not Allowed

#no-data-received

Returned when the request body is empty. On the data endpoint this means no meter payload was supplied; on the register endpoint it means no WebID was submitted.

Request: POST /api/data and POST /api/register

Response: 422 Unprocessable Entity

#not-found

Returned when a requested resource does not exist

Request: Any unknown or unsupported API route, or non-existing file in /data/

Response: 404 Not Found

#response-encoding-failed

Returned when the final problem or data response cannot be converted to JSON, for example because the response payload contains an unsupported value.

Request: JSON responses generated by web/index.php

Response: 500 Internal Server Error

#unexpected-error

Catch-all problem for uncaught exceptions that escape the API controller, including unexpected logic or routing failures.

Request: Any /api/ request handled by web/index.php

Response: 500 Internal Server Error

#unexpected-output

Returned when PHP emits output before the application finishes building the response. The captured output is included in the error detail for debugging.

Request: Any response path in web/index.php

Response: 500 Internal Server Error

#webid-already-registered

Returned when a submitted WebID has already been registered. Use PUT to update an existing registration (requires Authorization header).

Request: POST /api/register

Response: 409 Conflict

#write-failed

Returned when the storage layer throws a FilesystemException while checking, reading, writing, or creating stored API resources.

Request: Any /api/ request that triggers a Flysystem failure

Response: 502 Bad Gateway
